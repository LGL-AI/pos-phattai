# Unsigned compile proofs — v1.6.3

These APKs are not installable release packages. They demonstrate actual package,
version, launcher and updater authority for the two supported profiles. The current
production release is the signed APK referenced in `src/android-releases.json`;
its immutable asset is included under `public/releases/android/`. Historical
v1.6.2 binaries are available in the original ZIP identified in history/v1.6.2.
